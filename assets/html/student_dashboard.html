控制中心教材：指令示範與攻擊防範 SOP

先在控制中心閱讀教學，再進入遊戲實際操作。所有指令是否可用，會依教師設定的訓練難度而變化。

help

用途：列出目前難度可用指令。

示範：輸入 help，確認本局可用的防禦工具。

status

用途：查看 CPU、GPU、RAM、網路與破解進度。

示範：每次警報先輸入 status，建立系統負載基準。

ipconfig／ping [IP]

用途：確認主機網路設定與模擬連線。

示範：ipconfig、ping 10.0.0.1。

netstat

用途：查看目前連線、異常協定與可疑流量。

前置：先查看封包列表，再用 netstat 確認警報。

whois [IP/協定]

用途：分析來源並取得精準封鎖依據。

示範：whois udp、whois 103.24.55.12。

limit／unblock

用途：限速爭取時間，處理完畢後恢復服務。

示範：limit udp → 分析 → block [IP] → unblock udp。

block [IP/協定]

用途：建立阻擋規則。

注意：優先封鎖確認的惡意 IP，避免直接全域封鎖造成誤傷。

flush-dns／scan-mail

用途：處理 DNS 污染與釣魚郵件。

示範：whois dns → flush-dns；釣魚警報 → scan-mail。

passwd／clear

用途：passwd 到系統狀態更換本局密碼；clear 清除終端畫面。

注意：遊戲密碼與登入密碼分離，仍須符合教師密碼政策。

所有攻擊模式防範步驟

TCP／SYN Flood

  1. 查看 status。
  2. 用 netstat 找半開連線。
  3. 用 whois [IP] 分析來源。
  4. limit tcp 後精準 block [IP]。
  5. 恢復後 unblock tcp。

UDP Flood

  1. 封包列表篩選 UDP。
  2. 用 netstat 確認流量異常。
  3. 執行 whois udp。
  4. limit udp，確認來源後封鎖。

ICMP Flood

  1. 篩選 ICMP 封包。
  2. 檢查 Ping 頻率與封包大小。
  3. 執行 whois icmp 或分析來源 IP。
  4. 限速或精準封鎖，再確認負載下降。

DNS Amplification

  1. 觀察 DNS 放大回應。
  2. 執行 whois dns。
  3. 執行 flush-dns 清除污染快取。
  4. 持續監控，避免誤封正常 DNS。

密碼字典破解

  1. 用 status 觀察進度。
  2. 設定長密碼與數字、大小寫、特殊符號。
  3. 避免常見字典詞、連號與重複字元。
  4. 更換後確認破解進度歸零。

釣魚郵件

  1. 檢查寄件者、網域與急迫語氣。
  2. 不點擊、不回覆、不下載附件。
  3. 使用 scan-mail 隔離或安全刪除。
  4. 再用 status 確認系統狀態。
