教師與學生管理 SOP

  1. 確認學生帳號與教師綁定狀態。
  2. 核准前先確認申請者身分與所屬教師。
  3. 教師建立難度後，確認指令、攻擊、密碼政策與字典破解設定。
  4. 使用稽核紀錄中心確認升級、綁定、審核與題庫操作。

攻擊教材檢核

  • TCP／UDP／ICMP：確認學生能執行 status、netstat、whois，再限速與精準封鎖。
  • DNS：確認流程為 whois dns → flush-dns。
  • 密碼破解：檢查最低長度、字典破解開關與更換冷卻。
  • 釣魚郵件：確認學生使用 scan-mail，而不是點擊或回覆。
