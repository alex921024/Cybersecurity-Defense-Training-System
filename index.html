系統指令參考手冊 (Cheat Sheet)

指令範例寫法功能說明
statusstatus查看系統詳細負載狀態與密碼破解進度。
netstatnetstat顯示當前網路連線，若有 DDoS 或異常流量會跳出警告。
blockblock udp
block ip		設定防火牆。封鎖對應的協定或 IP。
flush-dnsflush-dns清除 DNS 快取。遭遇 DNS 攻擊或網址嫁接時使用。
scan-mailscan-mail自動掃描並隔離收件匣中的惡意釣魚信件。
passwdpasswd強制重置系統管理員密碼，將「破解進度」歸零。

⚠️ 常見攻擊處置指南 (SOP)

攻擊類型特徵與處置方式指令範例
SYN / ICMP Flood 【特徵】netstat 顯示大量異常封包。
【處置】封鎖惡意來源 IP，或擋下 Ping 洪水。		 block ip
UDP Flood 【特徵】Wireshark 出現大量紅色的 UDP 封包。
【處置】直接封鎖 UDP 流量。		 block udp
DNS 放大攻擊 【特徵】頻寬滿載，Wireshark 顯示異常 DNS 請求。
【處置】清除被污染的 DNS 快取。		 flush-dns
